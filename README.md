# IV Store - E-commerce

Production-ready Express + MongoDB ecommerce project with:
- Admin login/dashboard
- Category and product management
- User signup/login
- Product search/category pages
- Wishlist
- Persistent user cart with quantity controls
- Address management
- Razorpay checkout and payment verification
- Order history, order details and cancellation
- MongoDB-backed sessions for Heroku/production
- Responsive storefront

## Run locally
1. Copy `.env.example` to `.env`.
2. Fill in MongoDB, session and Razorpay credentials.
3. Run `npm install`.
4. Run `npm start`.
5. Open `/` for the storefront or `/admin/login` for admin.

Do not commit real secrets or `.env` to Git.
